## 设计解释
- 主键为什么存在：我们建表的时候把id设置成的主键。主键具有非空，唯一，不可变性，author,book的id需要这个性质
- 外键引用哪张表的哪一列：books表外键使用authors表的id列
- 价格为什么选择这个类型：decimal可以储存精确数据，比浮点数要好
